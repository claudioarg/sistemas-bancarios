Regla de Análisis Aplicada: Filtrado y Conexión de Textos Extensos (>40 Páginas)

Cumpliendo con tu instrucción expresa ("los textos de más de 40 hojas compáralo con respecto a los demás textos y solo recopila la información relacionada"), se han procesado de forma especial los dos textos que superan esa extensión: Facu 100 (Friedman - Metodología, 43 págs.) y Facu 97 (Chaves Barea - Demanda de Dinero, 61 págs.). Se descartó la paja irrelevante (debates microeconómicos marginalistas de los 40 y más de 35 páginas de cuadros econométricos ARDL de Argentina) para conservar exclusivamente el instrumental conceptual vinculado a los demás textos del programa.

Cómo Publicar Esta Página en Render Gratis en 2 Minutos

Para que puedas abrir este compendio desde tu celular, tablet o cualquier computadora en cualquier parte del mundo.

Opción 1 (Recomendada: 100% Gratis y Nunca se Duerme) Despliegue Inmediato

Render Static Site (Sitio Estático)

Los sitios estáticos en Render son 100% gratuitos para siempre, no tienen límites de horas al mes, tienen HTTPS seguro automático y nunca entran en reposo ni tienen demora de inicio.

1
Crea un repositorio en GitHub: Crea un nuevo repo (ej: sistemas-bancarios) y sube los archivos de esta carpeta.
git init
git add .
git commit -m "Compendio Sistemas Bancarios y Teoria Monetaria"
git branch -M main
git remote add origin https://github.com/TU_USUARIO/sistemas-bancarios.git
git push -u origin main
2
Entra a Render.com: Inicia sesión en render.com con tu cuenta de GitHub.
3
Crea un nuevo 'Static Site': Haz clic en New + → Static Site, conecta tu repositorio y configura:
  • Name: sistemas-bancarios (o el nombre que elijas)
  • Branch: main
  • Publish directory: static (o dejar vacío . si usas la raíz)
4
¡Listo!: Presiona Create Static Site. En 30 segundos obtendrás un enlace público como: https://sistemas-bancarios.onrender.com que podrás abrir desde tu celular, tablet o cualquier navegador.
Opción 2: Web Service con Python / Flask Backend Incluido

Render Web Service (Servidor Python)

Ya hemos preparado el archivo app.py, requirements.txt y Procfile para ti. Si prefieres un servidor Python con API REST:

  • En Render elige New + → Web Service.
  • Runtime: Python 3
  • Build Command: pip install -r requirements.txt
  • Start Command: gunicorn app:app
  • Elige el plan Free y presiona Deploy.

Probar Localmente en tu Computadora Ahora Mismo

No tienes que esperar a subirlo para probarlo. Puedes correrlo en tu máquina abriendo una terminal en esta carpeta y ejecutando:

python app.py

Luego abre tu navegador en http://localhost:5000 y verás la aplicación completa funcionando de inmediato.
